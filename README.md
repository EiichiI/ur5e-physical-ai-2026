# UR5e Physical AI Project 2026

## 1. プロジェクト概要

Physical AI講座2026 応用編1の最終課題として、AIの推論結果に基づいてロボットがタスクを実行するシステムの構築を目指します。

対象ロボットはUniversal Robots UR5eとRobotiq 2Fアダプティブグリッパーです。

## 2. 開発目標

1. 学習済みAIモデルで日本語の作業指示を推論する。
2. 推論結果に応じてロボットのタスクを選択する。
3. シミュレータ上でUR5eの動作を実行する。
4. 実行結果を動画として記録・評価する。

## 3. 使用予定の技術

- Python
- Google Colab
- Hugging Faceの学習済みモデル
- ROS 2 Jazzy
- MoveIt 2
- UR5e / Robotiq 2Fモデル
- シミュレーション環境（選定中）

## 4. システム構成（計画）

日本語指示 → AI推論 → タスク選択 → ロボット制御 → シミュレーション → 動画記録

## 5. 開発状況

現在は初期構築段階です。AI推論、ROS 2制御およびロボット動作の検証結果は、実装後に追加します。

- ロボットのタスク実行成功率

## 8. 注意事項

本プロジェクトはシミュレーションを中心とした教育・研究用です。実機への適用には別途安全性の検証が必要です。

## 9. 実装済みの機能

本プロジェクトでは、Hugging Faceの学習済みSentence Transformerモデルを用いて、日本語の作業指示からロボットの実行タスクを選択する機能を実装した。

選択されたタスクに応じて、MuJoCo上のUR5eロボットが、事前定義した関節目標姿勢へ移動する。

また、曖昧な指示に対してはREJECT（動作保留）を返す機能を設けた。

現段階ではRobotiq 2Fグリッパーによる把持・搬送、およびROS 2との連携は実装していない。

## 10. 実験結果

### AI推論性能

登録文と異なる日本語指示10件による評価を行った。

- 評価件数：10件
- 正解件数：6件
- 正答率：60.0%
- 誤判定：4件（明確な指示の棄却）

この結果は小規模な評価であり、一般的な認識性能や安全性を保証するものではない。

### ロボット動作

改良版65秒動画では、6つの指示についてAI推論とロボット動作を検証した。

- 移動指令：5件
- 関節目標への到達：5件
- 曖昧な指示の棄却：1件
- 最大関節角誤差：移動指令の終了時点で最大0.0129 rad

## 13. 第3回実習：UR5eとRobotiq 2F-85の統合

### 13.1 開発目的

第2回実習で構築したUR5eの動作シミュレーションを拡張するため、Robotiq 2F-85アダプティブグリッパーをMuJoCo上のUR5e先端に装着し、開閉制御の基本動作を検証した。

### 13.2 実装内容

- Google ColabとMuJoCoを使用
- UR5eとRobotiq 2F-85のシミュレーションモデルを結合
- グリッパーの開→閉→開の動作を実装
- 指令値と指関節角をCSV形式で記録
- 約11秒間の動作確認動画を生成

### 13.3 実験結果

- UR5eへのグリッパー装着：確認済み
- 開閉動作：確認済み
- 開閉指令値：0（開）、255（閉）
- 左右指関節：ほぼ対称に動作
- ログ記録件数：88件

今回の実験では、物体を配置せず、グリッパーの装着および開閉機構を検証した。

### 13.4 現段階の制約と今後の開発

本実習は開発途中の基礎検証である。日本語指示に対するAI推論とグリッパー開閉制御は、まだ統合していない。また、物体の把持・搬送、把持力評価、ROS 2連携は未実装である。

次の第4回実習では、AIによるタスク選択、UR5eの姿勢移動、Robotiq 2F-85の開閉を一連の動作として統合する。
