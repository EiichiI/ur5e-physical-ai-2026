# UR5e Physical AI Project 2026

## 1. プロジェクト概要

Physical AI講座2026 応用編1の最終課題として、AIの推論結果に基づいてロボットがタスクを実行するシステムの構築を目指します。

対象ロボットはUniversal Robots UR5eとRobotiq 2Fアダプティブグリッパーです。

## 2. 開発目標

1. 学習済みAIモデルで日本語の作業指示を推論する。
2. 推論結果に応じてロボットのタスクを選択する。
3. シミュレータ上でUR5eの動作を実行する。
4. 実行結果を動画として記録・評価する。

## 3. 使用予定の技術

- Python
- Google Colab
- Hugging Faceの学習済みモデル
- ROS 2 Jazzy
- MoveIt 2
- UR5e / Robotiq 2Fモデル
- シミュレーション環境（選定中）

## 4. システム構成（計画）

日本語指示 → AI推論 → タスク選択 → ロボット制御 → シミュレーション → 動画記録

## 5. 開発状況

現在は初期構築段階です。AI推論、ROS 2制御およびロボット動作の検証結果は、実装後に追加します。

## 6. 実行方法

開発環境と実行コマンドは、動作確認後に記載します。

## 7. 評価方法（計画）

- AIによるタスク選択の正答率
- ロボットのタスク実行成功率
- 推論時間と実行時間

## 8. 注意事項

本プロジェクトはシミュレーションを中心とした教育・研究用です。実機への適用には別途安全性の検証が必要です。
