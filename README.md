# UR5e Physical AI Project 2026

## 1. プロジェクト概要

Physical AI講座2026 応用編1の最終課題として、AIの推論結果に基づいてロボットがタスクを実行するシステムの構築を目指します。

対象ロボットはUniversal Robots UR5eとRobotiq 2Fアダプティブグリッパーです。

## 2. 開発目標

1. 学習済みAIモデルで日本語の作業指示を推論する。
2. 推論結果に応じてロボットのタスクを選択する。
3. シミュレータ上でUR5eの動作を実行する。
4. 実行結果を動画として記録・評価する。

## 9. 実装済みの機能

本プロジェクトでは、Hugging Faceの学習済みSentence Transformerモデルを用いて、日本語の作業指示からロボットの実行タスクを選択する機能を実装した。

選択されたタスクに応じて、MuJoCo上のUR5eロボットが、事前定義した関節目標姿勢へ移動する。

また、曖昧な指示に対してはREJECT（動作保留）を返す機能を設けた。

現段階ではRobotiq 2Fグリッパーによる把持・搬送、およびROS 2との連携は実装していない。

- ## 14. 第4回実習：AI推論とUR5e・Robotiq 2F-85の統合制御

### 14.1 開発目的

第2回実習で開発した「AI推論によるUR5eの姿勢制御」と、第3回実習で開発した「Robotiq 2F-85の開閉制御」を統合し、日本語の作業指示に基づいてロボットアームとグリッパーを連続動作させるシステムを試作した。

本実習は開発途中の機能統合試験であり、実際の物体把持・搬送の実現を目的としたものではない。

### 14.2 システム構成

- 実行環境：Google Colab
- シミュレータ：MuJoCo
- ロボット：Universal Robots UR5e
- グリッパー：Robotiq 2F-85
- AI推論：Hugging Faceの学習済みSentence Transformerモデル
- プログラミング言語：Python

**動作処理の流れ**

1. 日本語の作業指示を入力する。
2. AIモデルが指示内容を判定する。
3. LEFT_SAMPLEまたはRIGHT_SAMPLEと判定した場合、UR5eを事前定義した目標関節姿勢へ移動する。
4. グリッパーを閉じる。
5. グリッパーを開く。
6. UR5eをHOME姿勢へ復帰させる。
7. 指示が曖昧な場合はREJECTとし、新たな移動・開閉指令を発行しない。

なお、AIが推論しているのはタスクの選択であり、ロボットの運動軌道自体をAIが生成しているわけではない。

### 14.3 実験方法

左側指示、右側指示、曖昧な指示、HOME復帰指示の4種類を対象に、統合シミュレーションを実行した。

実験では、AIの判定結果、UR5eの関節目標との誤差、グリッパー指令値、指関節角、各動作フェーズの結果を記録した。

### 14.4 実験結果

| 評価項目 | 結果 |
|---|---|
| 動画長 | 22.50秒 |
| 動画フレーム数 | 180 |
| 動作フェーズログ | 10行 |
| AI入力指示 | 4種類 |
| 左側・右側への姿勢移動 | 各1回 |
| グリッパー閉開 | 2サイクル |
| HOME復帰 | 確認 |
| REJECT判定 | 確認 |
| 動作フェーズ終了時の最大関節目標誤差 | 0.0174 rad |
| 簡易目標到達判定（閾値0.12 rad） | 合格 |

グリッパーは、制御指令255（閉）で指関節角が約0.782 radとなり、制御指令0（開）で約0.0029 radに戻る動作を確認した。

REJECTの場合は、新規の移動・開閉指令を発行しないことを確認した。ただし、以前の指令に対する関節の微小な収束挙動は残る可能性がある。
